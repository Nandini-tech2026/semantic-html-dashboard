# Semantic HTML5 & Accessible Component Architecture

A single-page enterprise dashboard built with strict semantic HTML5 and accessibility best practices.

## Features
- Semantic tags: header, nav, main, section, article, aside, footer
- Navigation header, sidebar and main content area
- Data table with caption, thead, tbody, tfoot and scope attributes
- Modal dialog using the native dialog element with ARIA labels
- Accessible form with labels, fieldsets, legends, aria-describedby and validation attributes (required, pattern, minlength, type=email)
- Skip link, visible focus styles and responsive layout

## Validation
Checked with the W3C HTML Validator: 0 errors.

## How to run
Open index.html in any modern browser.
